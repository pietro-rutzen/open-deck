## Goal and scope

User request: finish the FLX4 functionality audit, make controllers plug-and-play with a rekordbox-like out-of-the-box experience, and make the app smoother and faster with no issues during a DJ set.

Root causes found for set-time sluggishness:

- Every non-jog control travelled MIDI → `controller:update` event → React state → IPC back to Rust.
- The MIDI callback also emitted raw `midi:cc`/`midi:note` for every message; `useMidiMap` set state per message, re-rendering the whole app for each 14-bit fader message.
- LED feedback re-sent about 100 `controller_feedback` IPC calls on every change.
- Master meter and engine-load events re-rendered the whole app at about 30 Hz, including the unmemoized library.
- Cue/loop/jump positions used the 30 Hz UI frame sample.

Non-goals: Pad FX, keyboard/stems, censor, loop-boundary jog adjust, beat-jump ×16, tempo range, rekordbox Beat FX DSP parity.
