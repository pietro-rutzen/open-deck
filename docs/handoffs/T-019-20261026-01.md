### M1 — one pad-mode LED per deck

`flx4_pad_mode_press` remembers the lit mode note for deck A and B. A new press sends 0 to the previous note before lighting the new one, so the feedback cache cannot stay stuck at 127. Activate, deactivate, and output-port change clear that memory, the PLAY notes, and the meters before the old port is dropped. UI transport-LED feedback is skipped only when the active profile is the FLX4 and the open port name contains `DDJ-FLX4`.

### M2 — consumed MIDI is not dispatched again

`midi:cc` and `midi:note` now include `consumed`. `useMidiMap` ignores a consumed event unless that panel is learning, and learning only binds. The instrument CC readout ignores consumed messages. App mount calls `controllerLearn(false)` before any raw-MIDI holder, so a reloaded webview cannot leave the controller thread in learn mode.

### M3 — one EQ band cannot wipe the others

`set_deck_eq` rejects an out-of-range deck and a non-finite gain, and clamps each band to ±26 dB before recording the shared store. A single on-screen band change calls `set_deck_eq_band`. The controller sends `EngineMsg::DeckEqBand`. The audio command updates one stored gain on the tone stage and recomputes coefficients from that stage's own three gains, so a concurrent writer cannot publish a stale snapshot of the other bands. A multi-band gesture (restore) still sends the full triple.

### Recommended minors

1. Effect level (channel 4, CC 2) is in the 14-bit pair table. Its LSB is CC 34. Whether the FLX4 actually sends that LSB is NOT RUN. If it sends only the MSB, the level knob will not move until an LSB arrives.
2. Every paired CC stores the MSB and applies only when the LSB arrives.
3. Covered by the EQ validation above.
4. Learn reset on mount, above.
5. PLAY and pad-mode LEDs are cleared with the meters, above.
6. Library browse and source browsing keep the latest index in a ref, updated inside the gesture, so two encoder ticks before the next render do not share one index.
7. Beat FX cycle turns the next effect on only when that deck does not already have it on.

Nits left as recorded by the review: passive FLX4 fader feedback still goes out over IPC; FLX4 pad-mode, browse, load, and LOOP IN are handled before user bindings; sync leader only sets the leader; MIDI input still uses an unbounded channel.
