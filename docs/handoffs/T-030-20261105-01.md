# T030 handoff

Completed on 2026-11-05 in the working tree based on aefba51. Root owned implementation. load_admission_review and command_audio_review independently reviewed the backend and audio boundary.

The sender accepts track load, replay gain and pitch reset as a group. The receiver consumes each group before reading the next channel message. Group handling runs on the control side. The existing audio-command ring still forwards individual commands. Jog updates can intervene and device loss can interrupt forwarding.

Engine status and diagnostics include current outstanding commands and their historical peak. Peak includes send reservations. When the control receiver exits, live backlog reads zero even if it abandoned a group tail. Failed sends roll back their own reservation.
